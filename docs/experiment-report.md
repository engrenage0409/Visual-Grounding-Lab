# Experiment report — Visual Grounding Lab (V1–V8)

**Date:** 2026-11-14  \
**Scope:** controlled synthetic referring-expression grounding; 224×224 colored shapes, multiple distractors and partial occlusion. **NOT a RefCOCO/real-image benchmark.**

## Research question

How does a vision-language model learn to map an image and a referring expression to a bounding box? We compare (i) frozen CLIP features + explicit box prediction, (ii) randomly initialized coordinate-token autoregressive decoders, and (iii) pretrained Qwen3-VL-2B-Instruct before/after task-specific 4-bit LoRA.

## Version history and measured results

| Version / model | Method | Validation split | Acc@IoU≥0.5 | Mean IoU | Interpretation |
|---|---|---|---:|---:|---|
| V1 | Frozen CLIP + single cross-attention + box MLP | early synthetic Mixed | ~5% | — | Global-feature box collapse; not directly comparable to corrected datasets |
| V2 | Spatial patch scoring, ViT-B/32 | early synthetic data | — | — | Initial generator had invalid/invisible triangle masks; exclude from clean-data comparison |
| V3 | ViT-B/16 patch granularity and triangle-mask generator fix | corrected synthetic data | — | — | Establish clean-data experiment |
| V4 ViT-B/32 | Spatial Grounder | Hard100 | **69%** | **0.5598** | 7×7 patch grid |
| V4 ViT-B/16 | Spatial Grounder | Hard100 | **80%** | **0.6150** | 14×14 patch grid |
| V5 | Region candidate ranking | Hard100 | **52%** | **0.4844** | Ranking and candidate quality worse than V4 |
| V5.1 | Anchor-free candidate ranking | Hard100 | **66%** | **0.5150** | Oracle Top-K stronger than selected Top-1 |
| V6 | Frozen V4 spatial head + pooled-scale ROI residual refinement | Hard100 | **86%** | **0.6272** | Improvement especially for smaller objects |
| V7 | Frozen CLIP + randomly initialized 2-layer coordinate-token decoder, 0–1000 | Hard100 | **0%** | **0.0537** | Low box quality despite declining token CE |
| V7.1 | Same architecture with 0–100 coordinate vocabulary | Hard100 | **0%** | **0.0748** | Lower token-entropy not enough |
| V7.2 generative | Frozen V6 spatial features/predicted box + generated absolute coordinates | Hard100 | **1%** | **0.0251** | Autoregressive decoder did not successfully use the supplied localization prior |
| V7.2 regression | Frozen V6 features/predicted box + residual box head | Hard100 | **87%** | **0.6323** | Minimal benefit over V6; unlike generative head, initialized as identity |
| V8 pretrained Qwen3-VL-2B-Instruct | Zero task-specific fine-tuning; 4-bit inference | Hard100 | **48%** | **0.473626** | Pretrained model already grounds many synthetic references |

The **same Hard100 set** is used for the rows labeled Hard100. Other early-version numbers were obtained with different or initially flawed synthetic datasets; they should not be ranked in the same benchmark. The V7.x model heads, pretrained Qwen, and V6 differ in architecture and training history; comparisons are descriptive, not controlled causal tests.

### V6 small-target effect

From the uploaded V4 B/16 and V6 Hard100 reports: V4 small-object accuracy **29/43 (67.44%)** → V6 **36/43 (83.72%)**; medium-object **51/57 (89.47%)** → **50/57 (87.72%)**. Paired V4→V6 transitions: eight corrections and two regressions, net six improved, which supports the hypothesis that this V6 refinement especially helps small objects. V6 draws two scales from the **same final CLIP feature map** (14×14 and pooled 7×7), **not** a multilevel FPN.

## Training and compute

- Hardware: user's RTX 5060 8GB, Windows/Conda `pytorch_env`.
- Qwen backbone: `Qwen/Qwen3-VL-2B-Instruct`; ms-swift **4.6.1**.
- Configuration: 4-bit bitsandbytes QLoRA; rank=8, alpha=16; `freeze_vit=true`, `freeze_aligner=true`; batch size=1 and gradient accumulation=4; 1 epoch on 800 training examples; 60 validation examples; LR=1e-4; `max_length=1024`; `IMAGE_MAX_TOKEN_NUM=256`.
- Training log: **200/200** optimizer steps, final `train_loss=0.7479`, validation `eval_loss=0.6279`, validation teacher-forced `eval_token_acc=0.7509`, reported `memory(GiB)=2.33`, 4m44s run time. **Token accuracy is not grounding Acc@0.5.**
- LoRA checkpoint stored locally under `checkpoints/qwen_grounding_lora/v2-20261114-010548/checkpoint-200`; large weights and local absolute paths should **not** be uploaded to public GitHub.

## Reproduce the final Qwen experiment

Install dependencies in a supported CUDA environment. ms-swift 4.x uses `--tuner_type lora` (**not** legacy `--train_type lora`). On Windows, the optional symlink warning does not mean the checkpoint failed.

```powershell
python -m pip install "ms-swift>=4.6,<5" "transformers>=4.57" peft accelerate bitsandbytes "qwen-vl-utils>=0.0.14" decord

python -m scripts.prepare_qwen_grounding --source data/v4_joint/train.jsonl --image-root data/v4_mixed --out data/qwen_grounding/train.jsonl
python -m scripts.prepare_qwen_grounding --source data/v4_mixed/val.jsonl --image-root data/v4_mixed --out data/qwen_grounding/val.jsonl

python -m scripts.evaluate_qwen_grounding --model Qwen/Qwen3-VL-2B-Instruct --data data/v4_hard/val.jsonl --image-root data/v4_hard --out results/qwen_before.csv

$env:IMAGE_MAX_TOKEN_NUM="256"
swift sft --model Qwen/Qwen3-VL-2B-Instruct --dataset data/qwen_grounding/train.jsonl --val_dataset data/qwen_grounding/val.jsonl --tuner_type lora --quant_method bnb --quant_bits 4 --torch_dtype bfloat16 --num_train_epochs 1 --per_device_train_batch_size 1 --per_device_eval_batch_size 1 --gradient_accumulation_steps 4 --gradient_checkpointing true --freeze_vit true --freeze_aligner true --lora_rank 8 --lora_alpha 16 --learning_rate 1e-4 --max_length 1024 --output_dir checkpoints/qwen_grounding_lora

python -m scripts.evaluate_qwen_grounding --model Qwen/Qwen3-VL-2B-Instruct --adapter checkpoints/qwen_grounding_lora/v2-20261114-010548/checkpoint-200 --data data/v4_hard/val.jsonl --image-root data/v4_hard --out results/qwen_after.csv
```

The checkpoint folder may differ on another run. For a fair comparison, baseline and fine-tuned model must receive **exactly the same image/text prompt, image split, decoding settings, coordinate convention and IoU evaluator**.

## What can and cannot be concluded?

**Supported:** For this synthetic distribution and this 100-example Hard evaluation, pretrained Qwen3-VL already exhibits non-trivial Grounding and 800-example QLoRA yields a large measurable improvement (+46 pp Acc@0.5). From-scratch coordinate generation on the small V7 task performed poorly; explicit spatial prediction/regression was much more reliable in these tested configurations.

**Not established:** That Qwen3-VL internally predicts/refines an initial candidate box; the exact causal origin of its pretrained grounding ability; that generated-coordinate grounding is inherently inferior to regression; or that 94% transfers to natural images and RefCOCO. A real-image benchmark, multi-seed trials, prompt ablation, pretraining/LoRA data-distribution checks, and visual inspection of failures are needed for stronger generalization claims.
